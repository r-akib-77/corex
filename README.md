# CoreX Arena & Academy

A modern, responsive website for **CoreX Arena & Academy**, a football turf and training destination in Mirpur, Dhaka, Bangladesh. The website introduces the venue, promotes turf bookings, highlights the academy, and helps visitors find the location and contact the team.

**Live Website:** https://corex-623.pages.dev/

---

## Overview

CoreX Arena's website is designed to give players, teams, and visitors a clear starting point for discovering the venue and planning their next match. It uses a sports-focused presentation with prominent calls to action, venue information, and location details.

The experience is organized around three core goals:

- **Play** — encourage visitors to book a football turf slot.
- **Train** — introduce visitors to the academy.
- **Compete** — position the venue as a place for team matches and football activities.

## Features

- **Sports-focused landing page** with the headline “Play. Train. Compete.”
- **Prominent calls to action** for booking a slot and exploring the academy.
- **Venue introduction** with football turf imagery and key highlights.
- **Location information** for CoreX Arena in Mirpur, Dhaka.
- **Opening hours** displayed clearly for visitors.
- **Contact details** to help users reach the venue.
- **Directions link** to help visitors navigate to the location.
- **Responsive-friendly content structure** intended to make essential information easy to find across screen sizes.

> **Scope note:** The public landing page presents booking and academy entry points. A live availability calendar, booking persistence, payment processing, authentication, and other backend behavior should only be documented as implemented if they are available and verified in the project source.

## User Experience

The main visitor journey is designed to be straightforward:

1. Discover CoreX Arena from the landing page.
2. Select the booking call to action or explore the academy.
3. Review the venue's location and opening hours.
4. Use the contact information or directions link to plan a visit.

## Design Principles

- **Clear visual hierarchy:** prominent messaging and calls to action.
- **Task-oriented navigation:** booking, academy, location, and contact information are easy to identify.
- **Sports-oriented identity:** football imagery and energetic messaging support the venue's brand.
- **Accessibility and usability:** maintain readable text, visible focus states, descriptive image alternatives, and sufficiently large interactive targets.
- **Responsive behavior:** ensure layouts and navigation work well on mobile, tablet, and desktop.
